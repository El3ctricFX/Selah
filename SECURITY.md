# Selah Security Policy

Selah is a work in progress. Security reports are welcome, especially reports that could expose private journal data, allow unauthorized access to local files, compromise application integrity, or put users' data at risk.

## Reporting a vulnerability

**Please do not report suspected vulnerabilities in a public GitHub issue or discussion.** A public report could expose users before a fix is available.

Use GitHub's private vulnerability reporting for Selah:

**[Report a vulnerability privately](https://github.com/El3ctricFX/Selah/security/advisories/new)**

Include, where possible:

- The affected Selah version, release, or commit.
- A clear description of the potential impact.
- Steps to reproduce the problem or a minimal proof of concept.
- Any relevant environment details.

Do not attach real `.selah` files, journal entries, prayer requests, personal photos, passwords, access tokens, or other private information. Use invented sample data when demonstrating a problem.

If GitHub's private reporting form is unavailable, contact the maintainer privately through the [El3ctricFX GitHub profile](https://github.com/El3ctricFX). Do not post exploit details publicly while seeking a contact method.

## What to expect

Selah is maintained as a personal project, so response and remediation times may vary. The maintainer will make a reasonable effort to review a report, ask for additional information if needed, and coordinate any public disclosure after the issue is understood and an appropriate fix or mitigation is available.

Please give the maintainer a reasonable opportunity to investigate before publicly disclosing a vulnerability. There is no guarantee that every report will result in a security advisory or a code change.

## Scope

Reports are especially useful when they demonstrate a reproducible security impact in Selah itself, such as unexpected access to files, exposure of private journal data, unsafe handling of imported content, or a dependency issue with a concrete impact on the application.

General questions, feature requests, and bugs without a security impact should be reported through the project's [issue tracker](https://github.com/El3ctricFX/Selah/issues).
